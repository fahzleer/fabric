🚀 Deploy Order — Step by Step

  1. Cloudflare — point fabric.cool
    Add site in Cloudflare dashboard. Update nameservers at your registrar. Wait ~10 min for propagation.
  2. Firebase Project setup
    Create project, upgrade to Blaze (pay-as-you-go), enable Realtime Database + Storage in asia-east1.
    firebase use production
  3. GCP Secret Manager — 2 secrets
    Store PASETO_KEY (64-char hex) and INTERNAL_SECRET.
    echo -n "$(openssl rand -hex 32)" | gcloud secrets create PASETO_KEY --data-file=-
    echo -n "$(openssl rand -hex 20)" | gcloud secrets create INTERNAL_SECRET --data-file=-
  4. Set Firebase Function env vars
    Stripe, Omise, Google, service URLs — set as plain env vars (not Secret Manager).
    firebase functions:secrets:set STRIPE_SECRET_KEY
    firebase functions:secrets:set OMISE_SECRET_KEY
  1. Deploy Firebase Functions
    Both Cloud Functions deploy. Copy the function URLs for the next steps.
    firebase deploy --only functions
  2. Create PostgreSQL database
    Use Neon or Supabase free tier. Copy the DATABASE_URL.
  3. Deploy Vercel (Next.js SSR)
    Set env vars: API_CORE_URL, NEXT_PUBLIC_API_CORE_URL, DATABASE_URL, BETTER_AUTH_SECRET.
    vercel --prod
  4. Deploy Cloudflare Worker
    Update wrangler.toml with real URLs, then deploy.
    cd apps/worker && wrangler deploy
  5. Deploy Firebase Hosting
    Build Next.js, upload static chunks to Firebase CDN.
    cd apps/web && bun run build
    cd ../.. && firebase deploy --only hosting
  6. Configure Webhooks
    Point Stripe and Omise webhook URLs to the deployed functions.
    Stripe: .../cfApi/webhooks/stripe
    Omise: .../cfCommerce/payment/omise/webhook
